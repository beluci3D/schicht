# SCHICHT

Private Konzeptseite für die Projektidee SCHICHT – ein Peer-to-Peer-Marktplatz für 3D-Druck.

- `index.html` – Startseite (DE/EN)
- `impressum.html`, `datenschutz.html` – Impressum und Datenschutzerklärung
- `fonts/` – lokal gehostete Schriften (SIL Open Font License 1.1), keine Google Fonts
